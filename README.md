# LectureTranscriber

[**⬇️ Скачать LectureTranscriber**](https://github.com/4UGUNIUM/Lecture_transcriber/releases/latest/download/LectureTranscriber-Windows-x64.zip)

Небольшая portable-программа для Windows 10/11: выбираете запись лекции, получаете обычный текст (`TXT`) и субтитры с таймкодами (`SRT`). Распознавание выполняется локально через [whisper.cpp](https://github.com/ggml-org/whisper.cpp) с Vulkan GPU; аудиозапись не отправляется в облако. Версия 1.3.1 обрабатывает всю лекцию одним проходом без предварительного VAD-разрезания и без повторной замены уже распознанных интервалов.

## Быстрый запуск готовой сборки

1. Распакуйте архив `LectureTranscriber-Windows-x64.zip`.
2. Запустите `LectureTranscriber.exe`.
3. Выберите модель и нажмите **Скачать модель**.
4. Браузер скачает `.bin`-файл, а программа откроет папку моделей. Переместите скачанный файл в эту папку без переименования.
5. Вернитесь в программу: она автоматически увидит модель.
6. Выберите `.m4a`, `.mp3`, `.wav`, `.aac`, `.wma`, `.mp4` или `.mov`, оставьте язык `Русский` и нажмите **Транскрибировать**.

Модели хранятся в `%LOCALAPPDATA%\LectureTranscriber\models`. Эта папка доступна по кнопке **Папка моделей**. После ручной загрузки модели интернет для распознавания не нужен.

EXE не подписан коммерческим сертификатом. Если Windows SmartScreen покажет предупреждение, сверяйте SHA-256 с файлом `SHA256SUMS.txt` из готового архива.

## Что умеет

- локальная транскрибация без учётной записи и облачного API;
- ускорение на дискретной видеокарте через Vulkan с предпочтением GPU перед встроенной графикой;
- непрерывный проход по всей записи: VAD не решает, какой звук дойдёт до Whisper;
- автоматическая нормализация тихих лекционных записей с защитой от клиппинга;
- beam search и штатный temperature fallback whisper.cpp;
- отключённый перенос текста между акустическими окнами: один неудачный фрагмент не отравляет всю оставшуюся лекцию;
- сохранение исходных сегментов Whisper и таймкодов без повторного «ремонта» и агрессивного перепаковывания;
- консервативное удаление только точных соседних дублей и пунктуационных хвостов;
- подавление неречевых токенов и отказ от скрытого многочасового CPU-режима;
- русский язык, автоматическое определение языка и английский;
- преобразование поддерживаемых Windows аудиоформатов в PCM 16 кГц mono;
- подсказка с терминами курса для редких фамилий и технических слов;
- просмотр результата внутри программы;
- сохранение `TXT` и `SRT`;
- кнопки для скачивания модели браузером и открытия постоянной папки моделей;
- отмена распознавания.

## Важные ограничения

- Требуется Vulkan 1.2-совместимый драйвер видеокарты. Для RTX 5070 он устанавливается вместе с актуальным драйвером NVIDIA.
- Если Vulkan GPU не обнаружен, программа выводит ошибку и не запускает медленный CPU-режим.
- Модель не включена в архив из-за её размера; её нужно один раз скачать браузером и поместить в папку моделей.
- Поддержка контейнеров и кодеков при преобразовании определяется Media Foundation в установленной Windows. Стандартные записи Windows/телефона в M4A, MP3 и WAV являются основным сценарием.
- Автоматическое разделение нескольких говорящих и генерация конспекта в версии 1.3.1 не выполняются.
- Для стабильности длинных лекций перенос текстового контекста между окнами отключён по умолчанию. Если заполнить поле терминов, включается небольшой контекстный бюджет ради подсказки модели; это осознанный компромисс.
- Качество зависит от шума, расстояния до преподавателя, громкости и выбранной модели. Результат следует вычитать перед использованием.

## Сборка из исходников

Требования:

- Windows 10/11 x64;
- Visual Studio 2022 с компонентом **Desktop development with C++**;
- CMake 3.21 или новее.
- Vulkan SDK с компилятором `glslc`.

PowerShell:

```powershell
./scripts/build-windows.ps1
./scripts/package.ps1
```

Первый скрипт собирает интерфейс, Vulkan-бэкенд и статически встраивает `whisper.cpp` по закреплённому commit SHA `371b5a7`. Второй скрипт формирует portable-папку `dist`.

Проект также собирается MinGW-w64 через `cmake/mingw-x64.cmake`.
